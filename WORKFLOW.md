# Workflow

Analyse → consolidate → iterate ×3 → ingest into RAG → next

## 1. Analyse

Read what exists. Name roles. Separate running from paper. Do not invent live surfaces.

## 2. Consolidate

One kernel (SysEx). Named modules only. Old MCT repos stay provenance. No merge of the fourteen.

## 3. Iterate ×3

1. Inventory — what each piece claimed vs what it did.
2. Cut — drop mega-mode, fake-live flags, ballots-as-product.
3. Chunk — one topic per retrieval unit.

## 4. Ingest into RAG

Embed only `rag/`:

- `rag/00-kernel.md`
- `rag/01-modules.md`
- `rag/02-ambiguity.md`
- `rag/03-surfaces.md`
- `rag/04-do-not.md`

Git is source of truth. Notion draft is a mirror, not the index.

## 5. Next

The first action that is still outside git and still required. Do not start a new repo for it.

- execute = false
- vendor_live = false
- hold = true
- no credentials in git
- label ≠ fact
